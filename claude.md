## Comments and docstrings
- Do NOT add docstrings to functions unless I ask. If one is needed, one line max.
- Never write multi-line """ """ docstrings with Args/Returns/Raises sections.
- No JSDoc /** */ blocks in JS/TS files.
- Only add a comment when the code does something non-obvious (a workaround, a gotcha, a magic number). Never comment what the code plainly does.
- Do not add comments explaining changes you made ("# updated to fix X"). Put that in your reply to me, not the code.
